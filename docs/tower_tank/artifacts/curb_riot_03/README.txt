CURB RIOT / 03 — skateboard asset

Файлы:
  curb_riot_03.blend — редактируемая модель, текстуры упакованы внутрь.
  curb_riot_03.glb — игровой экспорт, материалы и текстуры встроены.
  textures/ — исходные PNG BaseColor и Roughness, 2048 x 2048.
  source/deck_art_original.png — оригинал сгенерированного рисунка.
  source/texture_prompt.txt — точный запрос к встроенному image_gen.
  source/build_skateboard.py — воспроизводимая сборка Blender Python.
  source/validate_export.py — проверки .blend и бинарного GLB.
  validation.json — результат проверок и параметры объектов.
  preview_bottom.png, preview_top.png, preview_side.png — рендеры модели.

Иерархия игрового ассета:
Skateboard (Empty)
  Deck
  Grip
  FrontTruck
  BackTruck
  Wheels (Empty)
    Wheel0 — переднее левое
    Wheel1 — переднее правое
    Wheel2 — заднее левое
    Wheel3 — заднее правое

Все размеры в метрах. Blender: нос +Y, верх +Z, вправо +X.
Skateboard, Deck и Grip имеют origin (0, 0, 0).
Центры колёс Blender:
  Wheel0 (-0.19, +0.38, -0.105)
  Wheel1 (+0.19, +0.38, -0.105)
  Wheel2 (-0.19, -0.38, -0.105)
  Wheel3 (+0.19, -0.38, -0.105)
Колёса вращаются вокруг локальной X. Четыре объекта используют один mesh.
Rotation = (0,0,0), Scale = (1,1,1) у всех объектов игрового ассета.
Deck = 1.34 x 0.34 м, толщина дерева в центре 0.045 м.
Диаметр колеса 0.11 м, ширина 0.045 м.
Низ деки между подвесками плоский; нос немного выше хвоста.
Всего 5696 треугольников с учётом четырёх экземпляров колёс.

GLB экспортирован с +Y Up. Преобразование координат:
  Blender (x,y,z) -> glTF/Godot (x,z,-y).
Поэтому нос в GLB направлен по -Z, верх по +Y, ось вращения колёс — X.
Передние центры в GLB: (+/-0.19, -0.105, -0.38).
Задние центры в GLB: (+/-0.19, -0.105, +0.38).
Рига, анимаций и ног нет. Точки контакта, коллизии и код игры не изменены.

Художественная адаптация приложенного концепта; рисунок не является
попиксельной копией референса. Карта normal не используется.
Верх и низ имеют отдельные UV-поверхности и материалы, нос и хвост
не зеркалятся. Сцена освещения STUDIO и камера есть только в .blend.

Проверено в Blender 4.5.9 LTS: иерархия, origins, масштаб, размеры колёс,
общий mesh, число треугольников, UV, нормали, материалы, встроенные
текстуры, преобразование осей, отсутствие рига и анимаций.
Рендеры проверены визуально. Интеграция в игровую сцену не выполнялась.

Пересборка из корня рабочего проекта (PowerShell):
& '.\.tools\blender-4.5.9-windows-x64\blender.exe' --background --factory-startup --python 'artifacts\curb_riot_03\source\build_skateboard.py'
& '.\.tools\blender-4.5.9-windows-x64\blender.exe' --background --factory-startup --python 'artifacts\curb_riot_03\source\validate_export.py'

При переносе в игру достаточно GLB. Файл .gdignore в этой папке
предотвращает автоматический импорт рабочих исходников в текущий проект.
