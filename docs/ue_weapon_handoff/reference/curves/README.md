# Расчётные кривые для сравнения

CSV рассчитаны скриптом [build_package.py](../../tools/build_package.py) по формулам исходников. Это **не записанная телеметрия игры**: в расчёте нет ходьбы, столкновений, врагов и случайных импульсов. Единицы указаны в заголовках колонок. Скрипт воспроизводит полунеявный Euler с шагом 1/60 с; камера представлена непрерывными огибающими с выборкой 120 Hz.

| Файл | Условия |
|---|---|
| [cannon_isolated_60hz.csv](cannon_isolated_60hz.csv) | F=1, один горизонтальный выстрел, башня в покое. Откат ствола, один канал качания корпуса, оседание и свободный корневой откат. Без импульсов chamber/lock и реакций походки |
| [camera_single_shot_envelopes_120hz.csv](camera_single_shot_envelopes_120hz.csv) | Trauma стартует с 0,8, сила 1, Dground единичный. Только огибающие, без sin/cos-фазы и дополнительных попаданий |
| [crossbow_single_shot_60hz.csv](crossbow_single_shot_60hz.csv) | Один выстрел одного борта, предыдущее состояние покоя. Состояние recoil и реально применяемая поза mesh разделены |
| [crossbow_reload_targets_60hz.csv](crossbow_reload_targets_60hz.csv) | Целевая высота магазина и дополнительный feed-угол при Reload 7 с. Это цели; отображаемый feed ещё сглаживается по кратчайшей дуге с 20/с |
| [derived_metrics.json](derived_metrics.json) | Пик отката, первая применённая поза, максимальное оседание и свободный дискретный путь корня |

У пушки `simulation_s_excluding_hitstop=0` — записанное состояние сразу после Shot. Mesh ствола в этой строке ещё в предыдущей позе. Shot hitstop удерживает эту позу примерно три физических тика; дальше применяется первая интегрированная поза. Для физической временной оси CSV пауза исключена. Камера, наоборот, продолжает жить по render-времени во время hitstop: не сдвигать её кривую на 45 мс.

У арбалета состояние recoil=0,14 м выставляется после обновления mesh; следующий тик уменьшает его до 0,10 м и отображает. У reload lock состояние 0,10 м выставляется перед обновлением позы и уменьшается до 0,06 м в том же тике. Точное сохранение порядка важно при сравнении с 60-Hz эталоном.

Метки событий в reload CSV обозначают первый номинальный 60-Hz тик не раньше порога. Порог chamber=3,36 с попадает на 3,3667 с. При реальном вычитании float-таймера пограничное событие может сдвинуться на один тик; нормативные пороги остаются 48%, 90%, 100%.

Не импортировать CSV как полную анимацию боя: физический корень сталкивается с миром, походка добавляет свои импульсы, а перезарядка пушки дополнительно двигает пружину. Кривые нужны для изолированной настройки и поиска ошибок единиц/интегратора.
