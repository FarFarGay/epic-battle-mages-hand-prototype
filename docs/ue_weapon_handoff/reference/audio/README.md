# Звуковой эталон

WAV выгружены из синтезированного банка `sound.gd` текущего прототипа через Godot. Формат mono PCM16, 22050 Hz. Не применялись нормализация, громкость события, случайный pitch или пространственный микс. При запуске банк использует seed 4107; helper вызывает тот же `_ready`, поэтому порядок синтеза сохранён.

Громкость события в таблицах спецификации уже включает общий −5 dB из `sound.play`: **не вычитать его второй раз**. Pitch события дополнительно умножается на случайные 0,96…1,04; это изменяет также фактическую длительность WAV. В Godot звуки являются перекрывающимися 2D one-shot.

| WAV | Номинальная длина | Использование |
|---|---:|---|
| fire | 1,50 с | Выстрел пушки |
| impact | 1,15 с | Взрыв/попадание |
| eject | 0,50 с | Выброс гильзы |
| chamber | 0,58 с | Досылание обоих типов оружия с разным pitch |
| lock | 0,35 с | Затвор / защёлки |
| ready | 0,40 с | Готовность |
| repeater | 0,10 с | Один болт |
| bolt_hit | 0,12 с | Мелкое попадание |
| repeater_reload | 0,90 с | Начало смены общей обоймы |
| step | 0,42 с | Контекст: шаг/приземление, для сравнения массы тела |

Точные пути, gain и базовый pitch событий — в [parameters.json](../../parameters.json). Экспортёр — [export_audio.gd](../../tools/export_audio.gd). `export_metadata.json` содержит технические сведения headless-экспорта и отдельной camera probe: размер root viewport 64×64 оттуда **не является игровым разрешением**. Игровой эталон 1440×900 описан в спецификации.
