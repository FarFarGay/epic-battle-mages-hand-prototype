# Существующие проверки Godot

Здесь копии ранее полученных JSON-отчётов из проекта. Они приложены для понимания проверенных сценариев; **при подготовке документов тесты не запускались повторно**. Исходные даты файлов и число проверок записаны в [PACKAGE_CHECK.json](../../PACKAGE_CHECK.json), SHA-256 — в [MANIFEST.json](../../MANIFEST.json).

- [aim_result.json](aim_result.json): 9 проверок устойчивости прицела, отделения camera shake и стабилизации верхнего этажа.
- [crossbow_check.json](crossbow_check.json): 33 проверки очереди, 200 патронов, перезарядки, коллизий и контекстов. Метрика полной обоймы ≈9,9667 с включает дискретный шаг теста, поэтому отличается от 199 интервалов по 0,05 с.
- [battle_check.json](battle_check.json): 42 проверки боевых взаимодействий, включая попадания пушки и болтов по скелетам.
- [crew_damage_check.json](crew_damage_check.json): проверки урона экипажу и окружению.

Приложенные `aim_regression.gd` и `crossbow_regression.gd` показывают метод проверки, но требуют полного исходного проекта. Эти отчёты не доказывают прохождение UE-приёмки или субъективное равенство фила; для этого использовать [04_ACCEPTANCE.md](../../04_ACCEPTANCE.md).
