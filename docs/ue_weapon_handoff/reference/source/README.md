# Исходники эталона

Это неизменённые копии `.gd` из `docs/tower_tank/scripts` версии Iron Citadel 0.7.0. Файл `project.godot.reference` фиксирует настройки viewport, физики и версию. Полный список SHA-256 — в [MANIFEST.json](../../MANIFEST.json).

Папка предназначена для чтения и поиска функций из спецификаций. Это **не самостоятельный Godot-проект**: исходные `res://scripts/...` пути сохранены, сцены/импорт-кеш здесь не собраны. Для непосредственного сравнения запустить [готовый EXE](../../playable/IronCitadel.exe).

Код игрового прототипа при подготовке этого handoff не менялся. UE-команда может реализовать ту же механику своей архитектурой; предлагаемые отличия явно отмечены в основных документах.
