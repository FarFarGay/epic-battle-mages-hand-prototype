# Epic Battle Mages — спецификация оружия для UE

**Ревизия 1 · 15 сентября 2026 · эталон: Iron Citadel 0.7.0, Godot 4.7.**

Цель передачи — воспроизвести ощущение тяжёлого выстрела шагающей башни и скорострельных бортовых арбалетов. Здесь зафиксированы действующие параметры, формулы, события, визуальные и звуковые акценты. Документы описывают конкретный проверяемый результат; устройство классов UE команда выбирает самостоятельно.

## Как прочитать требования

В Git хранятся документы, исходники и небольшие референсные ассеты. Готовый EXE из таблицы входит в полный локальный ZIP-пакет; исполняемые сборки исключены из Git, как и в `docs/builds`.

**Эталон** — фактическое поведение исходников 0.7.0. Это стартовая настройка для сравнения. **Рекомендация UE** — предлагаемое техническое решение или исправление известной особенности прототипа; оно явно помечено и не выдаётся за уже реализованное. **Приёмка** — измеримый результат или визуальный сценарий.

Числа урона нужны, чтобы ощущения проверялись в одинаковых условиях. Будущий баланс боевого билда может меняться отдельно. До первого сравнения не менять одновременно тайминги, урон, размер эффектов и силу камеры: иначе невозможно понять, почему выстрел ощущается иначе.

## Основной образ

**Пушка:** моментальный тяжёлый толчок → короткое зависание тела → энергичный ход ствола назад → оседание башни → тяжёлая механическая перезарядка → отчётливый затвор → готовность. Попадание имеет свой импакт после времени полёта. Белый курсор остаётся точным, верхний этаж доворачивается с инерцией.

**Арбалеты:** непрерывная чередующаяся трескучая очередь двух механизмов, множество коротких болтов и небольших попаданий. Пушка остаётся главным тяжёлым акцентом, даже когда оба оружия работают одновременно. Долгая смена обоймы должна ощущаться контрастом к высокой плотности огня.

## Быстрое сравнение в эталоне

Запустить EXE. WASD — движение, мышь — наводка, ЛКМ — пушка, ПКМ — арбалеты, Tab — параметры фила. E — высадка/посадка; снаружи кнопки принадлежат гномам. Короткое нажатие и отпускание Space — дэш; удержание Space и ПКМ — супердэш. R — восстановить бой. Звук переключается на M.

Сначала сравнить одиночный выстрел стоя, затем выстрел поперёк движения, затем стрельбу при вращении корпуса. После этого — полную обойму арбалетов, смену обоймы и оба оружия одновременно. Камера по умолчанию ортографическая, 1440×900; эквивалентный масштаб UE описан в [03](03_AIM_CAMERA_UE.md).

В игровом EXE волны начинаются автоматически. Для спокойного сравнения можно запустить `IronCitadel.exe -- --reference`: непустые пользовательские аргументы отключают автоматические волны в этом прототипе. Мишени, управление и оружие сохраняются. Это существующее поведение 0.7.0, исходный код для передачи не менялся.

## Особенности, которые нельзя потерять при переносе

1. Луч мыши строится из камеры **до** тряски и изменения масштаба от выстрела.
2. Пушка стреляет по фактическому направлению ствола; золотой маркер только показывает его попадание.
3. 0,18 с наводки — постоянная времени сглаживания, а не ожидание перед поворотом.
4. 0,21 м — начальное положение отката, не максимальный ход: дальше работает пружина с начальной скоростью 16 м/с.
5. Перезарядка пушки 1,65 с считается по игровому времени вне hitstop. По настенным часам цикл немного длиннее.
6. Арбалеты имеют **одну общую обойму 200**, общий темп **20/с**, поочерёдные борта и перезарядку **7 с**.
7. Уже выпущенные снаряды живут независимо от кнопок и последующего выхода экипажа.

Решения по сетевой модели, окончательным ассетам и миксу боевого билда не принимались в Godot. Предложения по этим вопросам приведены отдельно; текущая спецификация не заявляет проверку UE-реализации.
