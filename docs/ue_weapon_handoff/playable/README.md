# Рабочий эталон Iron Citadel 0.7.0

`IronCitadel.exe` — существующий Windows x64 билд с ресурсами внутри. Установка Godot не требуется. Для спокойного полигона без автоматических волн запустить `PLAY_REFERENCE.cmd`; для обычного боя — сам EXE.

WASD — движение, мышь — наведение, ЛКМ — пушка, ПКМ — арбалеты, Tab — настройка фила, E — высадка/посадка, R — сброс полигона, M — звук, колесо — масштаб, Esc — выход. Дэш — короткий Space с отпусканием; удержание Space открывает прицел супердэша, ПКМ подтверждает.

Для корректного сравнения начать с default-параметров и включённого звука. Контрольные значения приведены в [спецификациях](../README.md). EXE скопирован без изменений из уже готового билда; SHA-256 указан в [MANIFEST.json](../MANIFEST.json).
